# 题材与类型系统

`genre` 用来约束读者期待和叙事承诺，不是固定公式。允许一个主类型搭配最多两个辅助类型，例如 `mystery + urban + romance`。

项目化写作时，`build_context.py` 会按 `genre.primary` 和 `genre.secondary` 自动加载已有的专门模块。目前 [悬疑](genres/mystery.md) 和 [言情](genres/romance.md) 有专门指导；其他类型使用下方的通用约束，不因没有专门模块而中断。

## 常用类型

### mystery / 悬疑推理

核心是信息控制与可回溯因果。重要线索在揭晓前应以某种形式出现；误导必须有角色动机或情境依据。章节常用问题、发现、反转或风险升级收尾。

### thriller / 惊悚

核心是持续压力、时间约束和后果升级。让角色为了短期安全做出会制造长期风险的选择，比单纯增加危险事件更有效。

### romance / 言情

核心是关系状态变化。外部事件应改变信任、依赖、欲望、误解或边界；避免只有事件推进而关系不动。

### fantasy / 奇幻

核心是规则、代价和陌生感。能力与世界规则需要可验证边界；解决关键冲突的新能力应提前种下来源、代价或限制。

### xianxia / 仙侠

除升级体系外，明确资源、门槛、代价、身份秩序与因果债。境界变化要改变角色可做的选择，而不只是数值变大。

### sci-fi / 科幻

至少有一个关键变化来自技术、科学假设或制度结果，并真实改变人物生活和冲突结构。重要技术能力同时说明限制、成本或副作用。

### historical / 历史

先确定时间与地域，再约束制度、称谓、交通、通信、职业、物质生活和社会关系。无法确认的细节应标记为待查证，不凭现代常识补全。

### urban / 都市

现实社会规则、职业流程、经济压力和空间距离应成为冲突的一部分。避免把城市只当背景板。

## 混合类型

主类型决定“读者为什么翻下一章”，辅助类型决定场景质感和次级回报。出现冲突时，先保证主类型的叙事承诺，再用辅助类型丰富角色与世界。
