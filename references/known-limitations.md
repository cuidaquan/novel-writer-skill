# 已知限制

- 脚本只验证结构与可复现问题，不能证明文学质量、人物弧或类型承诺是否真正成立。
- 文风阈值与画像分档是启发式，需用真实稿件校准；样本不足时明确不出结论。
- 占位/截断检查偏保守，对英文样本覆盖有限；知识边界提示只在作者真相逐字出现时触发。
- 项目 YAML 解析器只支持缩进映射/列表、标量与内联列表，不支持锚点、标签和多行块标量。
- 自动化测试在 macOS/POSIX 与 Python 3.9 上运行；Windows 未纳入自动化验证。
- 不提供旧项目导入或迁移，也不以修复既有生成稿的质量为目标。
- handoff_report 与 promise_report 的“未推进”判断基于事务更新时间，不判断暂缓在叙事上是否成立。
- 风格画像与偏移提示基于单章/少样本统计，不构成对作者声音的完整度量。
