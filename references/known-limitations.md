# 已知限制

- 脚本只验证结构与可复现问题，不能证明文学质量、人物弧或类型承诺是否真正成立。
- 文风阈值与画像分档是启发式，需用真实稿件校准；样本不足时明确不出结论。
- 占位/截断检查偏保守，对英文样本覆盖有限；知识边界提示只在作者真相逐字出现时触发。
- 项目 YAML 解析器只支持缩进映射/列表、标量与内联列表，不支持锚点、标签和多行块标量。
- 自动化测试在 macOS/POSIX 与 Python 3.9 上运行；Windows 未纳入自动化验证。
- 不提供旧项目导入或迁移，也不以修复既有生成稿的质量为目标。
- handoff_report 与 promise_report 的“未推进”判断基于事务更新时间，不判断暂缓在叙事上是否成立。
- 风格画像与偏移提示基于单章/少样本统计，不构成对作者声音的完整度量。
- 文风阈值偏保守：句长 ±30%、段落 ±40%、对话比例 ±0.25 以内不提示；实测约 ±25% 的偏离属已知漏报，可用 `tests/test_style_calibration.py` 复算。刻意的局部偏移应在章卡写 `style_override` 声明。
- 对话比例按“含引号的行，或以说话标签（`她说，`）开头的行”统计；引号同时接受全角与直引号。既无引号又无标签、只能靠上下文指认的对话仍会漏计。
- 结尾标点与引号闭合同样接受直引号：用直引号写作的中文稿和全角引号稿走同一套检查，两者混用也不会被误判。
- 规划字段标签容忍 `**加粗**`、反引号和省略列表符号；标签写作 `主角：`、`- 主角：`、`- **主角**：` 都算已填写，其他写法仍会报缺项。
- 重复开头/结尾的签名长度为 4 字，并跳过说话标签与整行不足 5 字的短回应；标点或引号层面的微小重复不在覆盖范围内。
- `timeline_audit.py` 只抽取文本里的时间陈述，不知道谁在某个时刻清醒、在家或在场：作息与场景互斥（「她在直播」却又「她下楼了」）仍需人工把依赖句排出来核对；跨章的时间账（第 3 章说两年、第 5 章说三年）它也不管。
- `duplicates.py` 只认字面重复：同一场戏换词重写的两份、跨语言的重复、以及"刻意的母题"与"顺手复用的叙述套路"之间的区别，都要人读。相似度阈值对短句偏敏感，短句对得上时先看是不是口语回环。
- 词频用连续汉字二元组近似，不能替代分词；标点频率与字符型例比只是观察，不设阈值，也不参与漂移或完结判定。
- 提交门禁的硬标记是文本启发式：`TO DO`、`{{`、`待补`、以及 `（后面接…）`／`（此处略）` 这类括注式草稿指令会阻断提交；误报请用 `--allow <check> --reason` 带记录放行，不要绕过脚本。`待定` 等歧义词只给提示。
- 类型承诺在没有 `payoff.id` 时按 `expected` 完全相同的文本分组；改措辞会被当成两条，跨章承诺建议写 id。
- `--compact-state` 默认最多保留 40 条活跃摘要，其余只计数；需要全量时调大 `--active-limit` 或运行 `handoff_report.py`。
